# v1 (2019–2022) — archived, not built, not linked

The hand-written HTML/CSS site that lived at
`peterfriedrich.github.io/main-portfolio/` until the Astro rebuild.

Kept as a working copy rather than left to `git log` for one reason: the project
blurbs in `index.html` are the only prose that exists for several of those
projects, and they are the source material when each one is written up as a real
portfolio entry or post. Nothing here is served — the build ignores this
directory entirely.

- `index.html` — the last live page (banner, About Me, project list)
- `old-pages/` — the pre-2022 version it replaced
- `images/` — moon banner variants and a web-app screenshot
- `style_test.css` — the stylesheet `index.html` loaded

**Do not edit these files.** If something here is worth keeping, port it forward
into `src/` and leave the original untouched.
