## 3. Technical Learnings
- **Astro is at 7.3.3**, well past the 5.x API in the model's training. The
  content-layer API was verified against the installed package rather than
  recalled: `src/content.config.ts`, `glob()` from `astro/loaders`,
  `render(entry)` from `astro:content` (not `entry.render()`), and `entry.id`
  as the slug (not `entry.slug`).
- **`node --test tests/` fails** in Node 22.22 — it resolves `tests` as a
  module. The working form is `node --test 'tests/*.test.mjs'`, which is what
  `npm test` runs.
- **The first version of the draft test was tautological.** Flipping
  `draft: true` → `false` changed both the assertion's input and its subject,
  so it passed either way. The real check is to break the *filter* in
  `src/lib/content.ts` while leaving the frontmatter alone — done, and the test
  failed correctly with `draft "how-this-site-works" has its own page in dist/`.
  Any future change to that test should be re-validated the same way.
- `check_decisions_log.py`'s `TEST_ID` regex only matched pytest / `verify-*.js`
  spellings; it needed `[a-z0-9-]+\.test\.mjs` added or every row would have
  read "names no test".
- Doc-citation guard: `src/content` is excluded from *scanning*. Published prose
  may legitimately write `file.js:40` about someone else's code; the line-number
  ban is for pointers this repo has to keep resolving.
